# Sala de Aula Inteligente

Projeto de IoT desenvolvido para monitorar as condições de uma sala de aula utilizando ESP32, sensores e um dashboard web.

## Objetivo

Coletar e processar dados do ambiente para apresentar informações sobre conforto, iluminação, presença, ocupação e qualidade do ar.

## Tecnologias e componentes

- **ESP32:** processamento dos dados.
- **Wokwi:** simulação do circuito.
- **DHT22:** temperatura e umidade.
- **LDR:** luminosidade.
- **PIR:** detecção de presença.
- **HC-SR04:** medição de distância e estimativa de ocupação.
- **MQ2:** indicador relativo de gases.
- **HTML, CSS e JavaScript:** desenvolvimento do dashboard web.

## Funcionalidades

- Monitoramento dos sensores.
- Índice de Conforto da Sala (ICS).
- Classificação das condições do ambiente.
- Gráficos e histórico das medições.
- Estatísticas e alertas automáticos.
- Exibição dos dados em um dashboard web.

## Equipe

Projeto desenvolvido em grupo para uma atividade prática de Internet das Coisas (IoT).
